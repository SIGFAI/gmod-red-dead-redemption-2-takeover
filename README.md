# Red Dead Redemption 2 Takeover

**Garry's Mod** × Red Dead Redemption 2 · visual · idea by the team

Bring Red Dead Redemption 2 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I dropped Red Dead into Garry's Mod: Dusty Gulch, Dead Eye slow-mo and bounties. Shooting TNT barrels and a horse stampede wrecked the gang.

## Install

Unzip the mod folder into garrysmod/addons/ as its own folder, then start Sandbox on any map. Dusty Gulch builds itself in the open, outlaws and deputies start shooting, and a Magnum-wielding bounty hunter plays the hero. No other content needed.
